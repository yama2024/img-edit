# 画像エディター

ブラウザ上で動作する画像編集アプリケーションです。

## 機能

- **画像のアップロード**: ファイル選択ボタンから画像を読み込み
- **画像のペースト**: Ctrl+V（Mac: Cmd+V）でクリップボードから画像を貼り付け
- **ペイントツール**:
  - ブラシ: 自由な描画
  - 消しゴム: 描画内容を消去
  - 色選択: カラーピッカーで好きな色を選択
  - 線の太さ調整: 1〜50pxの範囲で調整可能
- **テキスト入力**: キャンバス上にテキストを追加
  - フォントサイズ調整: 10〜100pxの範囲で調整可能
- **画像保存**: 編集した画像をPNG形式でダウンロード
- **クリア機能**: キャンバスをリセット
- **タッチデバイス対応**: スマートフォンやタブレットでも利用可能

## 使い方

1. ブラウザで `index.html` を開く
2. 「画像をアップロード」ボタンで画像を読み込む、または Ctrl+V で画像を貼り付け
3. ツールを選択してキャンバス上で編集
   - **ブラシ**: ドラッグして描画
   - **消しゴム**: ドラッグして消去
   - **テキスト**: クリックした位置にテキストを入力
4. 「画像を保存」ボタンで編集した画像をダウンロード

## ショートカットキー

- **Ctrl+V** (Mac: Cmd+V): クリップボードから画像を貼り付け
- **Ctrl+S** (Mac: Cmd+S): 画像を保存

## ローカルでの実行

```bash
# リポジトリをクローン
git clone <repository-url>

# ディレクトリに移動
cd img-edit

# ブラウザでindex.htmlを開く
# または、簡易サーバーを起動
python -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```
