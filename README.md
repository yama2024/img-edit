# 画像エディター

ブラウザ上で動作する画像編集アプリケーションです。

## 機能

### 📸 画像の読み込み（4つの方法）
- **ファイルアップロード**: 📁 画像をアップロードボタンから選択
- **ドラッグ&ドロップ**: 画像をキャンバスにドラッグ&ドロップ
- **キーボードペースト**: Ctrl+V（Mac: Cmd+V）でクリップボードから貼り付け
- **ペーストボタン**: 📋 ペーストボタンをクリック（クリップボードから）

### 🎨 ペイントツール
- **ブラシ**: 自由な描画
- **消しゴム**: 描画内容を消去
- **色選択**: カラーピッカーで好きな色を選択
- **線の太さ調整**: 1〜50pxの範囲で調整可能

### ✏️ テキスト入力
- キャンバス上にテキストを追加
- モダンなテキスト入力ダイアログ
- フォントサイズ調整: 10〜100pxの範囲で調整可能
- Enterキーで確定、Escapeキーでキャンセル

### 💾 その他の機能
- **画像保存**: 編集した画像をPNG形式でタイムスタンプ付きダウンロード
- **クリア機能**: キャンバスをリセット
- **リアルタイム通知**: 操作の成功/失敗を視覚的に表示
- **タッチデバイス対応**: スマートフォンやタブレットでも利用可能
- **ドラッグ視覚フィードバック**: ドラッグ中に背景色が変化

## 使い方

1. **画像を読み込む**（以下のいずれかの方法）
   - 📁 「画像をアップロード」ボタンをクリック
   - 🖱️ 画像ファイルをキャンバスにドラッグ&ドロップ
   - ⌨️ Ctrl+V (Mac: Cmd+V) でクリップボードから貼り付け
   - 📋 「ペースト」ボタンをクリック

2. **ツールを選択して編集**
   - **ブラシ**: ドラッグして描画
   - **消しゴム**: ドラッグして消去
   - **テキスト**: クリックした位置にテキストを入力

3. **画像を保存**
   - 💾 「画像を保存」ボタンをクリック
   - または Ctrl+S (Mac: Cmd+S) を押す

## ショートカットキー

- **Ctrl+V** (Mac: Cmd+V): クリップボードから画像を貼り付け
- **Ctrl+S** (Mac: Cmd+S): 画像を保存

## ローカルでの実行

```bash
# リポジトリをクローン
git clone <repository-url>

# ディレクトリに移動
cd img-edit

# ブラウザでindex.htmlを開く
# または、簡易サーバーを起動
python -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```
