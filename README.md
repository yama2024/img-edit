# 画像エディター

ブラウザ上で動作する画像編集アプリケーションです。

## 機能

### 📸 画像の読み込み（4つの方法）
- **ファイルアップロード**: 📁 画像をアップロードボタンから選択
- **ドラッグ&ドロップ**: 画像をキャンバスにドラッグ&ドロップ
- **キーボードペースト**: Ctrl+V（Mac: Cmd+V）でクリップボードから貼り付け
- **ペーストボタン**: 📋 ペーストボタンをクリック（クリップボードから）

### 🎨 ペイントツール
- **選択ツール**: 図形やテキストを選択・移動・編集
- **ブラシ**: 自由な描画（画像ロード後のみ使用可能）
- **消しゴム**: 描画内容を消去（画像ロード後のみ使用可能）
  - 消しゴムサイズを独立して調整可能（1〜100px）
- **色選択**: カラーピッカーで好きな色を選択
- **線の太さ調整**: 1〜50pxの範囲で調整可能

### 📐 図形描画
- **矩形**: ドラッグで長方形を描画
- **正方形**: アスペクト比1:1の正方形を描画
- **円**: ドラッグで円/楕円を描画
- **直線**: ドラッグで直線を描画
- **矢印**: 矢印付きの直線を描画
- **図形の選択・編集**:
  - クリックで図形を選択（8つのハンドルが表示）
  - ドラッグで移動
  - ハンドルをドラッグでサイズ変更
  - Deleteキーで削除
- **塗りつぶし/枠線**:
  - 塗りつぶし色と枠線色を個別に設定
  - チェックボックスで塗りつぶし/枠線のオン/オフ
- **リアルタイムプレビュー**: 描画中に図形をプレビュー表示

### ✏️ テキスト入力・編集
- **テキスト追加**: クリックで新規テキストを追加
- **テキスト選択**: テキストをクリックで選択（選択枠が表示）
- **テキスト移動**: 選択したテキストをドラッグで移動
- **テキスト編集**: ダブルクリックでテキスト内容を編集
- **テキスト削除**: Deleteキーで選択したテキストを削除
- モダンなテキスト入力ダイアログ
- **画像ロード後のみ使用可能**（画像がない場合は警告表示）
- フォントサイズ調整: 10〜100pxの範囲で調整可能
- 色の変更: カラーピッカーで自由に色を選択
- Enterキーで確定、Escapeキーでキャンセル

### ✂️ トリミング（プロフェッショナル品質）
- **8つのリサイズハンドル**: トリミング範囲の四隅と辺の中央に配置
- **範囲の移動**: トリミング範囲内をドラッグして自由に移動
- **範囲のリサイズ**: ハンドルをドラッグしてサイズ変更
- **3x3グリッド線**: 三分割法のガイドラインを表示（構図確認用）
- **範囲外オーバーレイ**: トリミング範囲外を暗くして選択範囲を強調
- **リアルタイムサイズ表示**: 現在の範囲サイズをピクセル単位で表示
- **範囲内のプレビュー**: トリミング中もテキストと図形を表示
- **操作手順**:
  1. トリミングボタンをクリック
  2. ドラッグで範囲を作成
  3. 範囲内をドラッグで移動、ハンドルでサイズ変更
  4. 適用ボタンでトリミング実行

### ⏮️ Undo機能（元に戻す）
- **Undo（元に戻す）**: Ctrl+Z（Mac: Cmd+Z）またはUndoボタン
- **履歴管理**: 最大50件の編集履歴を保持
- **自動保存**: すべての編集操作（図形追加、テキスト追加、描画、トリミングなど）後に自動保存

### 💾 その他の機能
- **画像保存**: 編集した画像をPNG形式でタイムスタンプ付きダウンロード
- **クリア機能**: キャンバスをリセット
- **リアルタイム通知**: 操作の成功/失敗を視覚的に表示
- **タッチデバイス対応**: スマートフォンやタブレットでも利用可能
- **ドラッグ視覚フィードバック**: ドラッグ中に背景色が変化
- **描画ツールの固定表示**: 画面スクロール時も描画ツールが常に表示
- **使い方ガイドのブロック化**: 6つのカードスタイルブロックで見やすく表示
- **UIのシンプル化**: すべてのラベルを短く、わかりやすく改善

## 使い方

1. **画像を読み込む**（以下のいずれかの方法）
   - 📁 「画像をアップロード」ボタンをクリック
   - 🖱️ 画像ファイルをキャンバスにドラッグ&ドロップ
   - ⌨️ Ctrl+V (Mac: Cmd+V) でクリップボードから貼り付け
   - 📋 「ペースト」ボタンをクリック

2. **ツールを選択して編集**
   - **選択**: 図形やテキストを選択・移動・編集
   - **ブラシ**: ドラッグして描画
   - **消しゴム**: ドラッグして消去
   - **テキスト**:
     - クリックでテキスト追加
     - テキストをクリックで選択
     - 選択したテキストをドラッグで移動
     - ダブルクリックでテキスト編集
     - Deleteキーで削除
   - **図形**（矩形・正方形・円・直線・矢印）:
     - ドラッグで図形を描画
     - クリックで図形を選択
     - ドラッグで移動、ハンドルでサイズ変更
     - Deleteキーで削除

3. **トリミング**（必要に応じて）
   - トリミングボタンをクリック
   - ドラッグで範囲を作成
   - 範囲内をドラッグで移動、ハンドルでサイズ変更
   - 適用ボタンでトリミング実行

4. **画像を保存**
   - 💾 「画像を保存」ボタンをクリック
   - または Ctrl+S (Mac: Cmd+S) を押す

## ショートカットキー

- **Ctrl+V** (Mac: Cmd+V): クリップボードから画像を貼り付け
- **Ctrl+S** (Mac: Cmd+S): 画像を保存
- **Ctrl+Z** (Mac: Cmd+Z): 元に戻す（Undo）
- **Delete**: 選択中のテキストまたは図形を削除
- **Enter**: テキスト入力ダイアログで確定
- **Escape**: テキスト入力ダイアログでキャンセル

## ローカルでの実行

```bash
# リポジトリをクローン
git clone <repository-url>

# ディレクトリに移動
cd img-edit

# ブラウザでindex.htmlを開く
# または、簡易サーバーを起動
python -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```
